# 使用说明

## 额度与来源

设置中的 Codex、ZCode 和轮播按钮选择当前额度来源；轮播每 10 秒切换一次。额度每 5 秒刷新，也可展开后手动刷新。液面表示剩余比例，同时显示重置时间和可用重置次数。

ZCode 个人套餐分别显示 5 小时、周额度和对应重置卡；展开可查看最近到期时间，过期卡不计入数量。体验套餐（Start Plan）可用时优先显示全宽单仓，并以 Expires 标记到期时间；不可用时回落个人套餐。ZCode 液体采用月光银，Codex Pro 单仓采用薄荷绿。

使用 Codex 来源前先登录 Codex；使用 ZCode 来源前先登录并启用相应编程套餐。QuoDex 会发现本机配置，不代替这些应用完成登录。重置卡读取失败会单独显示诊断，不影响已有额度展示。

## 聊天任务

Codex 和 ZCode 任务始终分成两组，与当前额度来源无关；一个聊天的多轮执行共用一个任务圆圈。

- 每组直接显示 5 个任务，超过时在名称行显示 `+N`，点击查看该来源全部任务。
- 1–2 个任务时名称在左侧，3 个及以上时名称上移。
- 区分运行、等待用户操作、报错、未知和近期成功；成功任务保留 30 分钟。
- 再次运行会更新当前状态。移除报错只移除当前轮次的提醒，不删除聊天。
- 悬停显示“项目名：聊天标题”；点击 Codex 圆圈打开聊天，点击 ZCode 圆圈打开项目。

ZCode 只读本地执行元数据；无法区分工具排队和等待批准时显示“状态未知”，退出 ZCode 后停止运行提示。

## 窗口与设置

按住浮窗非按钮区域拖动。右下角箭头展开额度详情和操作入口；展开后可切换窄条视图。右键主仓可打开设置，Esc 收起设置。

设置可切换来源和 ZCode 套餐、调节透明度、减少动效或退出。透明度即时预览，松手保存；写入失败保留所选值和诊断编号，可重试。关闭浮窗会隐藏到托盘或菜单栏，完全退出使用“退出”。

液体随拖动晃动：低液位波动较细快，中液位摆幅较大，高液位回摆较慢；空仓与满仓限制波高。减少动效可关闭晃动。展开操作还支持 10 秒鼠标穿透。

## 路由与诊断

TomatoCloud 监测读取系统代理并通过代理发起真实 HTTPS 探测，显示连接灯、出口国家和延迟。需要本机 TomatoCloud 客户端运行并启用系统 HTTPS 代理。健康时每 5 秒探测；阻塞或断开时每秒复测，连续两次失败后外沿红色闪烁报警。

数据读取失败保留最近一次有效数据，并显示稳定诊断码。报告问题时提供系统版本、复现步骤和诊断码，勿公开令牌或真实聊天内容。端点与路径覆盖见 [开发与构建](DEVELOPMENT.md#环境变量覆盖)。

## 数据与隐私

Codex 额度通过独立本机 `app-server` 的只读 JSON-RPC 获取，认证与网络通信由 Codex 运行时处理。任务状态读取本机桌面 IPC 和 SQLite 执行记录。

ZCode 额度读取本机配置中的 API Key 并请求对应配额接口；个人套餐重置卡读取匹配账号的本机加密登录凭据，向对应服务查询。体验套餐由套餐网关判定授权状态。

QuoDex 不修改聊天或账号配额，不自动消耗重置卡，不上传任务内容。不读取其他进程内存或浏览器 Cookie。TomatoCloud 探测使用系统代理和公开 HTTPS 端点，不读取其私有日志、配置、IPC 或凭据。
