# 设置里的额度轮播

Windows 浮窗的轮播有三个预设来源：Codex、ZCode、Gemini。首次设置时三项全选。贯穿三张设计稿的例子是取消 ZCode 后的画面。Gemini 的 Web、AG Gemini 和 AG Claude/GPT 随同一张额度卡一起出现。[三个方案](options.png) · [窄条设计](compact.png) · [可操作的设计稿](preview.html)

## 三种设置方式

| 方案 | 用户怎样只轮播 Codex 和 Gemini | 布局取舍 |
| --- | --- | --- |
| A · 就地展开（推荐） | 点现有顶行的「轮播」，在紧邻的「轮播来源」行取消 ZCode。 | 三个固定查看入口始终可见。只有轮播模式会多出一行，标准浮窗与窄条都能看全三个名称。 |
| B · 固定 / 轮播 | 先选「轮播」，再在三个来源里取消 ZCode。 | 三个名称只出现一次。切回「固定」后，同一行变为单选，查看单个额度要经过模式切换。 |
| C · 独立清单 | 从轮播摘要进入编辑，在三行清单里取消 ZCode，返回设置。 | 每个来源都有整行点击区域，窄条容易操作，多一次进入与返回。 |

三稿沿用设置坞现有的水膜玻璃外壳、来源透镜和页脚反馈。勾号表示该来源参与轮播，来源名称始终可读。[已通过的设置外观](../../verification/waterfilm/waterfilm-dark-native.png) · [现有设置组件](../../../src/SettingsDock.tsx)

## 轮播规则

- 三个预设始终列在 Windows 名单里，可选全部或任意两项。只需看一个来源时，可点固定查看入口。若用户在剩两项时再点已勾选项，保留这两项，并就地提示「轮播至少选择两个 Agent」。
- 沿用现有的 10 秒间隔和 Codex → ZCode → Gemini 顺序，跳过未勾选项。例如取消 ZCode 后，显示 Codex → Gemini → Codex。若取消的正是当前额度卡，立即进入下一个选中来源，从该卡重新计满 10 秒。
- 勾选后即时生效并自动保存。编辑中遇到额度卡轮换，名单保持展开，键盘焦点留在正在操作的选项。临时固定查看 ZCode 后，再点「轮播」，仍使用先前勾选的 Codex 和 Gemini。顶部聊天任务环独立显示，ZCode 任务照常可见。
- 轮播名单随显示偏好保存在本机。首次使用新名单默认三项全选，已保存的名单在重启后恢复。升级时保留原先的固定查看或轮播模式。保存失败时保留本次勾选值，在原有页脚显示原因、诊断编号与「重试」。

## 正式实施时的验收

复用显示偏好的写入队列和轮播计时器，新增一份明确的来源名单。手动查看 Gemini 只切换当前额度卡。A 的来源行展开时，把实际增高计入原生设置窗口的高度预算，覆盖桌面边缘、详情和保存失败同时出现的情况。[现有轮播逻辑](../../../src/App.tsx) · [设置窗口尺寸](../../../src/windowClient.ts) · [本机偏好](../../../src-tauri/src/preferences.rs)

在 300 px 标准浮窗和 260 px 窄条分别操作。首次进入看到三项全选，取消 ZCode 后观察完整一圈，只出现 Codex 和 Gemini。临时固定查看 ZCode、再返回和重启后均保留组合。键盘可逐项到达，按空格切换，每项都有可辨认的选中反馈。此轮交付设计稿，正式浮窗实现待选定方案。
