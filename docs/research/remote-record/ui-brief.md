## 页面合同

首屏主任务是在原统计页查看全部设备已记录用量；“全部设备 / 本机”是新增范围选择，与 Codex / ZCode 合并或分开正交。用户无需重新输入系统已知的来源、日期与本机身份。

同步详情显示每台设备最后上传时间与本机待上传量，设置进入二级。统计页与传输品牌解耦，连接流程按主方案已选择的百度个人应用绘制。约一分钟是正常在线小批同步的目标节奏，不是所有历史同步完成的时限；限流时退避。

五态覆盖首屏、同步中、成功、失败和窄屏。失败保留已显示的账目，附可行动原因与 `QDS-101` 示例诊断编号；诊断编号尚待实现时登记。窄屏改为单列，不缩小可操作控件。

成功仅表示本轮可见对象已同步；离线设备未上传的新记录仍未知，不能显示“全设备实时完整”。日期统一 Asia/Shanghai。演示总量 18,831,000 = Codex 12,035,000 + ZCode 6,796,000；不使用真实用户标识或内容。
