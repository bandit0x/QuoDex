# 单包浏览器会话实验

2026-11-25 在 Windows、Chrome 158.0.8127.37、Python 3.11.9 环境，从项目根目录运行以下命令。

```powershell
python docs/research/gemini-background-probe/verify-browser-session.py
```

脚本在回环地址启动假站点，在全新临时目录启动系统自带的 Chrome（可回退到已安装的 Edge）。登录完成回调设置一条仅限假站点的 HttpOnly 持久会话。脚本按它刚启动的 PID 和随机标题匹配可见窗口并关闭该窗口。随后用相同的独立目录启动无窗口浏览器，等页面脚本异步生成两个周期，从渲染结果读取用量行。运行全程不安装扩展或驱动，不访问 Google 或用户默认浏览器配置。

| 场景 | 实际返回 |
| --- | --- |
| 可见测试窗口关闭后首次读取 | 五小时剩余 73%，每周剩余 88% |
| 服务端修改数值后再次读取 | 五小时剩余 69%，每周剩余 82% |
| 服务端撤销该测试会话 | `Sign in required` |

这验证了同一浏览器专用目录在可见与无窗口进程之间接续持久会话，并重新取得动态数据。Google 对专用目录中真实登录的接受程度、真实额度页面结构和失效后恢复，需要真实账号独立验收。
