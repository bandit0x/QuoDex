# QuoDex v0.2.5

此版本包含任务状态实时性修复、ZCode 重置卡显示，以及随液位变化的双仓晃动。

- 修复 macOS 的 Codex 任务状态连接，历史聊天的超时不再阻断其他任务更新。
- 修复 ZCode 刚开启与重新执行的任务沿用旧完成状态的问题，识别本机正在运行的桌面进程。
- ZCode 个人套餐分别显示可用的 5 小时卡、周卡及最近到期时间，排除过期卡，并核对当前登录账户与配额账户。
- 卡查询失败时显示独立原因和诊断，额度继续可用；慢响应不会被每次轮询重复作废。
- 低液位细碎快波、中液位摆幅最大、高液位慢回摆；两仓节奏独立，低帧率下也能收敛，减少动效设置继续有效。

重置卡只读现有登录状态，不领取或使用卡，不修改登录凭据及历史。

安装包由标签 CI 构建：Windows 使用 NSIS 安装器，macOS Apple Silicon 使用 DMG。更新前关闭 QuoDex，再替换或安装新版本。

本轮现场验证环境为 macOS arm64；Windows 原生运行未现场复测，双平台测试与打包结果以此标签的 GitHub Actions 为准。
