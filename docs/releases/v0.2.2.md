# QuoDex v0.2.2

## 任务显示改进

- 悬停详情和溢出列表显示“项目名：聊天标题”。
- Codex 优先使用应用保存的项目名，缺失时使用目录名；ZCode 显示所属项目目录名。
- 圆圈继续显示状态和完成分钟数，保留现有水流呼吸动效和单行布局。

## 修复

修复 Codex 桌面最新轮次与滞后的历史记录不同步时，已完成或报错任务被误显示为“未知”的问题。成功提醒仍保留 30 分钟，取消任务移除；缺失或无效结束时间继续显示诊断信息。

## 下载与升级

- Windows 11 x64：下载 `QuoDex-0.2.2-win-x64-setup.exe`，关闭正在运行的 QuoDex 后安装。安装器包含 Codex 与 WebView2 运行时。
- macOS Apple Silicon：下载 `QuoDex_0.2.2_aarch64.dmg`。DMG 包含捆绑的 Codex 运行时；macOS 支持仍为实验性，尚未进行现场验证。

## 已知限制

- 窗口重启时可能上移 36px，本次尚未修复。
- ZCode 的普通待执行工具无法区分排队与等待批准时仍显示“状态未知”；点击圆圈打开所属项目。
- Codex 状态依赖桌面内部协议，协议变化或来源不可用时会显示未知与诊断信息。
- 真实当前聊天的运行已核对；等待 / 完成切换与 ZCode 项目跳转采用协议及系统处理器夹具复测，不代表所有真实旅程均已验证。
