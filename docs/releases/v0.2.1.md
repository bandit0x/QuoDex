# QuoDex v0.2.1

## 新增任务状态

- Codex 与 ZCode 任务在驾驶舱上方同一行显示，切换额度来源不影响任务列表。
- 运行中的任务显示呼吸灯与变化的水流边缘；完成后显示绿色勾和结束分钟数，如 `10m`，保留 30 分钟。
- 等待操作显示暂停圈，报错显示感叹号；报错可手动移除，再次运行时恢复；取消的任务移除。
- 单行最多显示 10 个位置，超出后使用 `...`，点击查看其余任务。
- 悬停查看详情；点击 Codex 圆圈打开对应聊天，点击 ZCode 圆圈打开所属项目。

## 界面调整

缩小状态圈，调整描边和圈内完成时间排版；缩短状态栏与驾驶舱的间距，并加粗运行时的水流边缘。

## 下载与升级

- Windows 11 x64：运行 `QuoDex-0.2.1-win-x64-setup.exe`，安装包自带 Codex 与固定 WebView2 运行时。
- macOS：使用 `.dmg` 安装包；任务状态监测本次只在 Windows 进行现场验证，macOS 支持仍为实验性。

## 已知边界

ZCode 的普通待执行工具记录无法区分排队与等待批准时显示“状态未知”；可打开所属项目确认。部分状态来自本地执行元数据，不能保证每个 Agent 子进程的实时健康。ZCode 的入口打开所属项目，不能直接定位具体聊天。
